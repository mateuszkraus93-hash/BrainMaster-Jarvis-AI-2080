## 🚀 Czym jest JARVIS 2080?

JARVIS 2080 to **autonomiczny system AI klasy operating-system orchestration engine**. Działa lokalnie na Twoim komputerze, widzi Twój ekran i kamerę w czasie rzeczywistym, automatyzuje pulpit Windows, uczy się Twoich preferencji, podejmuje decyzje i ewoluuje samodzielnie.

**To nie jest kolejny chatbot API.**  
**To nie jest wrapper na GPT.**  
**To nie jest demo.**

**To jest w pełni autonomiczny runtime AI, który:**

- 👁️ **Widzi Cię** przez kamerę — rozpoznaje twarze, emocje, gesty, liczbę palców
- 🖥️ **Widzi Twój ekran** — czyta tekst, śledzi aktywne okna, reaguje na zmiany
- 🤖 **Automatyzuje Windows** — uruchamia aplikacje, klika, pisze, robi zrzuty, organizuje pulpit
- 🧠 **Myśli samodzielnie** — podejmuje decyzje, planuje, optymalizuje
- 📝 **Pisze kod** — generuje, testuje, naprawia, skanuje pod kątem bezpieczeństwa
- 🌐 **Szuka w internecie** — prawdziwe wyniki, nie symulowane
- 💾 **Pamięta Cię** — uczy się Twoich preferencji, faktów, historii rozmów
- 🔒 **Jest bezpieczny** — dual-pass security, sandbox, OWASP Top 10
